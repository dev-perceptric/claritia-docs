ClickUp is an all-in-one work app for tasks, docs, goals and projects. Teams use it to plan work, assign tasks and track progress in one place.

With Claritia, you can make a ClickUp task for each form fill.

| | |
| - | - |
| Category | Tasks and tickets |
| Connects with | Sign in with ClickUp |
| Used in | A form's **Sync** tab |
| Who can connect | Workspace owners |
| Plan | Starter and up |

## Connect ClickUp

Only workspace owners can connect or disconnect tools. Other members see the card and its state.

<Steps>

1. **Open Integrations**

   Go to **Settings**, then **Integrations**. Type "ClickUp" in **Search integrations**, or pick **Tasks and tickets** in the category menu.

1. **Click Connect**

   The button reads **Opening…** while ClickUp's sign-in page loads. Sign in to ClickUp and approve Claritia.

1. **Come back to Claritia**

   You land back on **Integrations**. The card shows **Connected**, and the account you signed in with when there is one.

</Steps>

If ClickUp's sign-in isn't set up on Claritia's side, Connect tells you and opens a short form for a **Personal API token** instead. You can also open the card and click **Use a key instead**. Keys are only a fallback.

## What Claritia can do in ClickUp

When you connect, Claritia asks for this access:

- See your ClickUp spaces and lists.
- Create a new task for every form fill.
- Find tasks it made before, so it never makes the same one twice.

## Make a ClickUp task for each fill

<Steps>

1. **Open the form's Sync tab**

   Open the form, click **Sync** and pick **ClickUp** on the left.

1. **Turn it on**

   Click **Send rows to ClickUp**.

1. **Pick the list**

   Choose from **Pick a list**. It reads **Reading…** while Claritia loads them from ClickUp. Claritia says **Fills go to [name] now**.

</Steps>

Each fill becomes one task in that list, with every answer inside.

To switch, use **Use another table** or pick again. To stop, click **Turn off** and confirm. Fills stay in Claritia.

## What syncs

| | |
| - | - |
| Direction | Claritia to ClickUp. Claritia reads your lists so you can pick one. |
| What's sent | One task for each fill, with every answer. |
| Repeats | A fill sent twice still makes only one. |
| When | Right after each fill. If the tool is busy or down, Claritia tries again after about 1, 5 and 30 minutes, then 2 and 6 hours. |
| While off | Fills are kept. When you turn it on again, what it held is sent, oldest first. |

## What teams use it for

- Every form fill becomes a ClickUp task in the list you pick.
- Client requests turn into tasks your team can assign and track.
- Answers show up inside the task, so nothing gets lost.

## Disconnect

In **Settings**, then **Integrations**, click **Disconnect** on the ClickUp card, or open the card and click it there. Confirm **Disconnect ClickUp?**. Forms stop sending to it. What was already sent stays in ClickUp.
